# Kahai Dashboard — IT101 Dashboard

A personal Chiang Mai dashboard submitted as the teacher-approved dashboard alternative to the CV lab.

## Website
https://kahai25.github.io/kahai-dashboard/

## Features
Current weather, tomorrow and seven-day forecasts, Chiang Mai and Mobile clocks, USD/THB/MMK conversion, modeled air quality, sunrise/sunset, and an external Google Maps traffic link.

All HTML, CSS, JavaScript, and AI-created decorative artwork are embedded in index.html. No installation or build step is required.

## Sources and limits
- Weather: Open-Meteo (https://open-meteo.com/).
- Air quality: CAMS via Open-Meteo; modeled values, not a local sensor.
- Daily indicative exchange rates: ExchangeRate-API (https://www.exchangerate-api.com/). MMK local cash rates may differ.
- Traffic opens an external Google Maps view; no traffic measurements are simulated.
- Hero scenery is AI-created, not a live view.

## Publishing
GitHub Pages deploys from the main branch, root folder.
